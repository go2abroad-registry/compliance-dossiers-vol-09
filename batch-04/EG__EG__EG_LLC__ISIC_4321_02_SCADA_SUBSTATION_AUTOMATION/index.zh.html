法定实缴资本与验资锁资账户流程 强制验资锁定

根据2009年第4号法律，有限责任公司无需缴纳法定最低注册资本；资本可由股东在设立合同中自由确定，并可分期缴纳。除非股东选择以其他方式证明已缴纳出资额，否则无需使用托管或银行资本存款证明。

注资与解冻路径: 根据1981年第12号《民防法》颁发的民防机构认证，涵盖仓储、测试及集结区域的消防系统；由主管省工程部门出具的结构承重 clearance，用于永久办公场所的装修及设备架设；根据2003年第12号《劳动法》由人力资源部进行的职业健康与安全检查，包括急救包、灭火器、人员防护装备、电气接地及电弧闪络防护等在投产工程中的合规性检查。

实缴资本规则: 根据2009年第4号法律，有限责任公司无需缴纳法定最低注册资本；资本可由股东在设立合同中自由确定，并可分期缴纳。除非股东选择以其他方式证明已缴纳出资额，否则无需使用托管或银行资本存款证明。

董事会首期决议范本 (Pro-Forma First Board Resolution)
经公司创始股东一致同意，达成如下决议：1. 在相关公证处进行公证的《成立合同》及《公司章程》已得到完全确认和通过，附上的股份认购名单也作为公司的资本清单予以认可。2. 公司的注册地址为《成立合同》中指定的开罗省地址；总经理有权签署租赁协议，并向GAFI提交相关文件。3. 合同中所列的认购人被任命为总经理，作为唯一法律代表，拥有开立银行账户、签署文件及办理法定手续的权力。4. GAFI有权完成公司注册手续并颁发《公司成立证明》。

跨境出口 0% 零税率申报条件

零税率适用于通过海关出口申报证明已出口到埃及境外的可移动货物，以及提供给非居民或直接与出口货物相关的服务。前提是法律上的所有权转移给国外的接收方，且费用能够以外币支付。

  • 海关出口申报
  • 提单（或空运提单）
  • 来自埃及持牌银行的汇款证明

所有 B2B 交易都必须执行强制性的实时电子发票开具，并需通过 ETA 认可的 API 以 XML/JSON 格式传输，且必须进行数字签名，并加盖唯一的二维码。ETA 的电子收据系统适用于 B2C 交易销售。未与系统整合的供应商将面临处罚，且无法抵扣进项增值税。

ETA在出口文件不完整或申报错误的情况下拒绝零税率，并收回所有已免除的增值税，以及最高可达未缴税款100%的滞纳金。虚假零税率申报将依据埃及税收欺诈规定面临刑事起诉、罚款以及被禁止使用电子发票或出口相关设施的风险。ETA通过自动化审计程序，将电子出口申报数据与海关数据及银行外币信贷记录进行比对核实。

经常项目兑换自由度

埃及实行有管理的浮动汇率制度，资本项目可兑换程度在一定程度上已实现行政上的自由化。根据2020年第194号法律第54条，经埃及中央银行（CBE）授权的银行在核实相关文件后，货物、服务、特许权使用费和技术费等经常项目交易可完全自由兑换。资本项目交易，包括股权增资、公司间贷款和清算所得，须事先获得埃及中央银行的批准或依据2017年第72号《埃及投资法》进行登记。非居民股东的利润和股息汇出在法律上是被允许的，但实际操作中需提供经审计的财务报表、企业所得税清缴证明、ETA税务清关证明，并通过经授权的银行以现行银行间市场汇率办理汇出；短期内外币流动性紧张可能导致汇款延迟，但并不构成正式的法律禁止。

出口外汇强制结汇要求

没有强制性的货币兑换比例要求转换为埃及镑；之前的放弃机制已被取消，这是2016年及后续CBE交易改革的一部分措施。出口商必须在货物发运之日（航空运单或提单日期）起180天内，将所有出口收入汇回由埃及授权银行持有的外币账户中，但可根据CBE规定的延期规定进行办理。所收集到的收入可以保留以美元或欧元形式，用于支付进口供应商的款项，或者自愿出售给银行。未能在规定的期限内提供出口信贷，即构成CBE合规违约行为，可能导致进口融资受到限制、被提交给CBE违规委员会处理，以及该违约实体未来无法获得出口信贷支持。

央行监管: 埃及中央银行（CBE）依据2020年第194号法律《中央银行与银行体系法》，并由投资与自由区总局（GAFI）负责投资者注册、埃及税务机关（ETA）负责与税务清关相关的外汇汇款。

跨境清算通道与结算适配

外资母公司对子公司的股权注入必须 exclusively 通过经埃及中央银行授权的埃及银行进行。母公司应通过SWIFT MT103电汇方式汇款，收款人名称须与有限责任公司商业注册登记信息完全一致，汇款须注明GAFI项目编号，并明确申报“埃及直接投资”（股本/股本增加）的对外支付目的代码。收款银行将资金划入资本托管账户，并完成最终受益人（UBO）核实、税务卡验证及商业注册信息筛查后，方可将资金划转至有限责任公司的运营账户。银行随后应出具《境内汇款证明书》，该文件须由有限责任公司妥善保存，以备后续利润汇回、债务转股本及清算清关等用途。所有底层公司文件（包括公司设立证书、公司章程、董事会决议、母公司财务报表、护照复印件及商业注册信息摘要）在首次提款前，均须经过公证、领事认证（或经认证的阿拉伯语翻译）及经认证的阿拉伯语翻译。对于PLC模块、SCADA服务器、中压开关设备及变电站自动化硬件的进口，主要结算方式为由信誉良好的海外代理银行确认的不可撤销的单据信用证，通过SWIFT MT103/MT202报文完成结算。服务费、工程费以及低于银行信用证额度的低值分包付款，将通过LLC的美元或埃镑账户直接通过SWIFT MT103报文支付。埃及中央银行（CBE）要求所有发票必须完整且有据可查，所有进入埃及的货物均需完成海关Form 4/ACI预登记，并注明相应的贸易合同。每笔交易须建立专门的贸易文件，内容包括提单或航空运单、原产地证明、保险单、装箱单、供应商发票以及现场验收文件，以满足银行尽职调查及未来ETA审计查询的要求。境内美元/埃镑商业远期合约，期限最长为180天，须与经核实的进口或出口单据严格对应，不得用于投机目的。在埃及交易所（EGX）交易的美元/埃镑期货合约，通过经批准的经纪商进行结算，并用于对冲已确认的采购订单。由获中央银行（CBE）授权的银行财会部门执行的以埃镑（EGP）与美元（USD）为交易货币的交叉货币互换，用于项目融资现金流匹配，前提是获得中央银行的无异议以及存在相应的贸易或投资敞口。外汇掉期（即期买入并同时远期卖出）仅用于在已承诺的供应链义务中，调整埃镑与美元之间的营运资金平衡。离岸美元/埃镑非交割远期（NDF）：对境内埃及企业不可行；根据中央银行（CBE）结算规则，要求资金必须通过境内银行间市场实际交割，因此被排除。

转让定价与经济实质

主文档/本地文档门槛: 在纳税年度内，相关方交易的总额达到80万美元，将触发必须提交附属于表19的TP-1申报表、完整的本地文件，并且对于集团范围内的报告，还需准备主文件（根据2018年第1202号部长令修订版）。

经济实质审查范围: 埃及尚未制定类似于海湾合作委员会（GCC）体系的独立经济实质法规；然而，根据2005年第91号所得税法第99条的反避税一般规则、实质重于形式原则以及转让定价规定，埃及税务管理局（ETA）有权忽视虚假或人为的交易；享受税收协定优惠待遇需证明在居住国存在可证实的经济活动、人员、场所及运营实质。

致命合规红线与董事个人责任

逃税

法定制裁: 根据2005年第91号所得税法第133-134条，可处以不少于6个月至5年的监禁，并处以10,000至100,000埃及镑的罚款；必须补缴逃税款，还需缴纳35%的额外评估附加费以及2%的每月延迟支付滞纳金；ETA会冻结银行账户并没收相关资产作为预防措施。

董事个人责任: 签署虚假财务报表的董事，须就公司税款短缺、罚款及滞纳金承担连带及按份责任；在存在欺诈情形下，若揭开公司法人面纱，监管机构可将董事列入登船禁令名单，实施旅行禁令，并可查封其个人财产。
转让定价不合规

法定制裁: ETA根据最佳判断方法重新评估，需额外支付35%的溢价及每月2%的附加费；根据2020年第25号《统一税务程序法》，可能面临最高10万埃及镑的行政罚款；对于无凭证的集团内部费用，则无法享受扣除优惠。

董事个人责任: 董事需承担未足额缴纳公司税款的民事赔偿责任及罚款；若明知故意伪造税前文档，将构成逃税罪，可能面临监禁、旅行禁令以及被剥夺董事职位的处罚。
空壳公司与税收协定滥用

法定制裁: 忽略或重新定性根据第99条GAAR条款的安排；拒绝享受双边税收协定待遇；以35%的额外溢价重新核定应税收入为22.5%；取消税务卡、商业注册注销以及依据2020年第159号公司法规定的欺诈处罚。

董事个人责任: 当有限责任公司被用作仅有的掩饰手段时，公司面纱就会被突破；董事需对逃税、罚款和损失承担个人责任，并可能面临刑事起诉、旅行禁令以及因欺诈而可能被监禁的处罚。
预提税欺诈与反洗钱合规问题

法定制裁: 被扣押的税款可直接从法定代表人处收回；每月需缴纳2%的附加税；未按时缴纳则面临犯罪挪用资金相关处罚；根据2002年第80号法律，违反反洗钱规定可处以最高5年的监禁、50,000至500,000埃及镑的罚款以及资产冻结措施。

董事个人责任: 董事作为法定代扣代缴义务人，须就未缴清的预提税金额、附加费及刑事罚款承担个人责任；若证实存在欺诈性未代扣行为， principals（实际受益人）将面临监禁、禁止出境、资产查封执行以及个人破产风险。
